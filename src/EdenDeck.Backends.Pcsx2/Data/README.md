`ps2-names.tsv.gz` holds game names only (no disc data, no links), keyed by disc serial, plus the
first 16 hex digits of each single-file DVD image's SHA-1 (so a DVD .chd can be recognised from
its header). It is generated by `tools/ps2names/gen.py` from the Redump metadata in
[libretro-database](https://github.com/libretro/libretro-database) and, like that source, is
licensed under CC BY-SA 4.0.
