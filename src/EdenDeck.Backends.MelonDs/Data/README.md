`ds-names.tsv.gz` holds game names only (no ROM data, no links): `s<CODE>` lines map a cartridge's
game code ("AMCE") to its No-Intro name, and `h<CODE>` lines name the game's cheat file in
libretro-database's `cht/Nintendo - Nintendo DS` folder, where it has one. It is generated by
`tools/dsnames/gen.py` from [libretro-database](https://github.com/libretro/libretro-database) and,
like that source, is licensed under CC BY-SA 4.0.
