`ps1-names.tsv.gz` holds game names only (no disc data, no links), keyed by disc serial, plus each
Redump name in lower case mapped to its serial (so a .chd named after its Redump entry can be
recognised without reading it). It is generated by `tools/ps1names/gen.py` from the Redump metadata
in [libretro-database](https://github.com/libretro/libretro-database) and, like that source, is
licensed under CC BY-SA 4.0.
