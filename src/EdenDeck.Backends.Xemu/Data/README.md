`xbox-names.tsv.gz` holds game names only (no disc data, no links), keyed by the serial printed on
the disc ("MS-004", which Scanline derives from the title id in the game's XBE). It is generated by
`tools/xboxnames/gen.py` from the Redump metadata in
[libretro-database](https://github.com/libretro/libretro-database) and, like that source, is
licensed under CC BY-SA 4.0.
